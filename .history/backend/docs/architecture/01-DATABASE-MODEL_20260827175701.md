# Livrable 1 : Modèle de Base de Données Relationnelle - CertiUni

Ce document spécifie le schéma relationnel PostgreSQL géré via l'ORM Prisma pour la plateforme CertiUni.

---

## 1. Schéma Entité-Association (8 Tables)

### 1.1 `universities` (Tenants)
* `id` (UUID, PK)
* `name` (VARCHAR 255)
* `code` (VARCHAR 50, UNIQUE) — Ex: UY1, UDa
* `domain` (VARCHAR 255, UNIQUE)
* `created_at` (TIMESTAMP)

### 1.2 `users` (Comptes d'accès)
* `id` (UUID, PK)
* `university_id` (UUID, FK -> universities.id, NULLABLE pour SuperAdmin)
* `email` (VARCHAR 255, UNIQUE)
* `password_hash` (VARCHAR 255)
* `role` (ENUM: SUPER_ADMIN, ADMIN_UNIV, ISSUER)
* `mfa_secret` (VARCHAR 255, NULLABLE)
* `created_at` (TIMESTAMP)

### 1.3 `students` (Bénéficiaires)
* `id` (UUID, PK)
* `university_id` (UUID, FK -> universities.id)
* `student_id_number` (VARCHAR 100) — Matricule
* `first_name` (VARCHAR 100)
* `last_name` (VARCHAR 100)
* `email` (VARCHAR 255)
* `created_at` (TIMESTAMP)
* *Contrainte :* UNIQUE(`university_id`, `student_id_number`)

### 1.4 `certificates` (Registres des diplômes)
* `id` (UUID, PK)
* `university_id` (UUID, FK -> universities.id)
* `student_id` (UUID, FK -> students.id)
* `hash_sha256` (CHAR 64, UNIQUE, INDEX B-TREE) — Empreinte cryptographique
* `degree_type` (VARCHAR 100) — Ex: Licenciation, Master
* `field_of_study` (VARCHAR 255)
* `issue_date` (TIMESTAMP)
* `status` (ENUM: VALID, REVOKED) — Défaut: VALID
* `pdf_s3_key` (VARCHAR 512)
* `qr_code_url` (VARCHAR 512)
* `created_at` (TIMESTAMP)

### 1.5 `revocations` (Historique des révocations)
* `id` (UUID, PK)
* `certificate_id` (UUID, FK -> certificates.id, UNIQUE)
* `revoked_by` (UUID, FK -> users.id)
* `reason` (TEXT)
* `revoked_at` (TIMESTAMP)

### 1.6 `batches` (Ingestions de masse)
* `id` (UUID, PK)
* `university_id` (UUID, FK -> universities.id)
* `created_by` (UUID, FK -> users.id)
* `file_name` (VARCHAR 255)
* `total_records` (INT)
* `processed_records` (INT)
* `status` (ENUM: PENDING, PROCESSING, COMPLETED, FAILED)
* `created_at` (TIMESTAMP)

### 1.7 `verification_logs` (Statistiques & Détection de fraudes)
* `id` (UUID, PK)
* `certificate_id` (UUID, FK -> certificates.id, NULLABLE)
* `searched_hash` (CHAR 64)
* `ip_address` (VARCHAR 45)
* `user_agent` (TEXT)
* `result` (ENUM: VALID, REVOKED, INVALID)
* `verified_at` (TIMESTAMP)

### 1.8 `security_audit_logs` (Journal d'audit immutable)
* `id` (UUID, PK)
* `user_id` (UUID, FK -> users.id, NULLABLE)
* `action` (VARCHAR 100) — Ex: USER_LOGIN, CERTIFICATE_REVOKED
* `details` (JSONB)
* `ip_address` (VARCHAR 45)
* `created_at` (TIMESTAMP)
