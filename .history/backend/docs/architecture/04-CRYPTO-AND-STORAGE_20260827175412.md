# Livrable 4 : Stratégie Cryptographique & Stockage S3 - CertiUni

Ce document spécifie les mécanismes d'intégrité des données, la méthode de calcul du hash SHA-256 canonique, la structure d'archivage S3 et la politique d'immutabilité WORM.

---

## 1. Empreinte Cryptographique (Hash SHA-256 Canonique)

Afin d'éviter qu'une variation mineure d'espacement ou d'ordre des clés dans le JSON ne génère un hash différent pour les mêmes données, l'API applique une **sérialisation canonique JSON (RFC 8785)** avant le hachage.

### 1.1 Algorithme de Génération du Hash
1. Extraire la structure exacte des données du diplôme.
2. Trier les clés du JSON par ordre alphabétique.
3. Formater la chaîne UTF-8 sans espaces inutiles.
4. Appliquer l'algorithme `SHA-256`.
