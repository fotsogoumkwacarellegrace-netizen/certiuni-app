# Livrable 2 : Architecture Sécurité & Authentification - CertiUni

## 1. Stratégie d'Authentification (Dual Token)
- **Access Token :** Durée 15 min | Stockage : Mémoire Angular | Format : JWT (RS256/HS256)
- **Refresh Token :** Durée 7 jours | Stockage : Cookie HttpOnly, Secure, SameSite=Strict
- **Route de rafraîchissement :** `POST /api/v1/auth/refresh`

## 2. Matrice des Rôles et Droits (RBAC)
- **PUBLIC :** `GET /api/v1/verify/:hash`
- **STUDENT :** `GET /api/v1/wallet/me`
- **ADMIN_UNIV :** `POST /api/v1/batch/upload` (Isolé au tenant)
- **SUPERADMIN_MINESUP :** `POST /api/v1/universities` (Vue globale)

## 3. Stratégie de Rate Limiting (Redis)
- **Vérification Publique :** 30 req/min/IP (Blocage 15 min après 10 échecs consécutifs)
- **Connexion/MFA :** 5 tentatives / 15 min / IP
- **Ingestion Batch :** 10 req/heure / compte Admin

## 4. Traçabilité (Security Audit Logs)
Toute action d'écriture ou tentative suspecte est enregistrée dans la table `security_audit_logs` (IP, User-Agent, user_id, university_id, action).
