# Livrable 4 : Stratégie Cryptographique & Stockage S3 - CertiUni

Ce document spécifie les mécanismes d'intégrité des données, la méthode de calcul du hash SHA-256 canonique, la structure d'archivage S3 et la politique d'immutabilité WORM.

---

## 1. Empreinte Cryptographique (Hash SHA-256 Canonique)

Afin d'éviter qu'une variation mineure d'espacement ou d'ordre des clés dans le JSON ne génère un hash différent pour les mêmes données, l'API applique une **sérialisation canonique JSON (RFC 8785)** avant le hachage.

### 1.1 Algorithme de Génération du Hash
1. Extraire la structure exacte des données du diplôme.
2. Trier les clés du JSON par ordre alphabétique.
3. Formater la chaîne UTF-8 sans espaces inutiles.
4. Appliquer l'algorithme `SHA-256`.

### 1.2 Structure des Données d'Entrée
```json
{
  "academic_year": "2025-2026",
  "degree_type": "MASTER",

  "student_first_name": "Jean",

2. Stratégie de Stockage S3 & Immutabilité WORM
Les fichiers PDF générés par le Worker de tâche doivent être stockés sur un service compatible S3 (AWS S3 ou MinIO local) avec une protection stricte contre toute altération ou suppression.

2.1 Arborescence & Convention de Nommage des Objet S3
Plaintext
s3://certiuni-diplomas-bucket/
└── {university_code}/
    └── {academic_year}/
        └── {hash_sha256}.pdf
Exemple : s3://certiuni-diplomas-bucket/UY1/2025-2026/e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855.pdf

2.2 Verrouillage S3 Object Lock (Mode WORM)
Mode : COMPLIANCE (Aucun utilisateur, y compris l'administrateur Root S3, ne peut supprimer ou modifier le fichier pendant la période définie).

Durée de rétention : 10 ans (RetentionPeriodYears: 10).

2.3 Politique de Sécurité du Bucket (S3 Bucket Policy)
JSON
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowPublicReadForValidCertificatesViaPresignedUrlOnly",
      "Effect": "Deny",
      "Principal": "*",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::certiuni-diplomas-bucket/*",
      "Condition": {
        "StringNotLike": {
          "aws:PrincipalArn": ["arn:aws:iam::123456789012:role/CertiUniBackendRole"]
        }
      }
    }
  ]
}
3. Accès Sécurisé aux Fichiers (Pre-Signed URLs)
Pour empêcher le téléchargement direct ou sauvage des diplômes PDF :

Le bucket S3 est 100 % privé.

Lors d'une demande de téléchargement par un étudiant ou un gestionnaire autorisé, le backend génère une Pre-Signed URL temporaire.

Durée de validité : 15 minutes max (Expires: 900).

### 3. COMMENT SAVOIR si votre livrable est correct ou s'il y a une erreur ?

Pour valider l'exactitude de ce livrable :

#### A. Les 3 règles de contrôle cryptographique & S3
* **Contrôle 1 (Canonicalisation) :** La section doit obligatoirement mentionner la sérialisation canonique (ex: `canonicalize` ou RFC 8785) avant le calcul du SHA-256. *Si vous hachez un JSON brut non trié, la moindre modification d'espace annulera la vérification !*
* **Contrôle 2 (Nommage S3) :** Les fichiers PDF stockés sur S3 doivent porter comme nom leur propre **hash SHA-256** (ex: `{hash}.pdf`). Cela évite les doublons et garantit l'adressage par le contenu.
* **Contrôle 3 (Mode WORM) :** La mention du S3 **Object Lock** en mode `COMPLIANCE` doit figurer noir sur blanc pour répondre aux exigences légales d'infalsifiabilité des diplômes.
